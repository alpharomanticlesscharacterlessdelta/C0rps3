# Workflow And Examples

### 1. Investigate domain DNS & registration
C0rps3> dns target.com <br>
C0rps3> whois target.com

### 2. Check IP infrastructure and geolocation
C0rps3> geo 8.8.8.8<br>
C0rps3> shodan host 8.8.8.8

### 3. People and identity discovery
C0rps3> user johndoe<br>
C0rps3> email target@example.com<br>
C0rps3> phone +14155552671<br>

### 4. Aggregated full footprinting scan
C0rps3> deep domain target.com<br>

### 5. Clear or exit
C0rps3> clear<br>
C0rps3> exit
